================================================================================
  PHASE 3 — GCP INFRASTRUCTURE SETUP (Biggest manual phase)
================================================================================

STEP 9 — Create GCS buckets:
  Run in PowerShell (replace YOUR_PROJECT_ID):

  gsutil mb -p YOUR_PROJECT_ID -l us-central1 gs://apu-model-artifacts-YOUR_PROJECT_ID/
  gsutil mb -p YOUR_PROJECT_ID -l us-central1 gs://apu-incoming-data-YOUR_PROJECT_ID/

  Verify:
  gsutil ls
  (Should show both buckets)

STEP 10 — Upload model files to GCS:
  (Run these from project root with venv activated)

  gsutil cp Artifacts/Model/model_LGBM.pkl gs://apu-model-artifacts-YOUR_PROJECT_ID/model_LGBM.pkl
  gsutil cp Artifacts/Scaler/scaler.pkl    gs://apu-model-artifacts-YOUR_PROJECT_ID/scaler.pkl
  gsutil cp Artifacts/baseline_stats.json  gs://apu-model-artifacts-YOUR_PROJECT_ID/baseline_stats.json

  Also upload original NASA training data (needed for retraining):
  gsutil cp Artifacts/raw/train_FD002.csv  gs://apu-model-artifacts-YOUR_PROJECT_ID/train_FD002.csv

  Verify all 4 files are there:
  gsutil ls gs://apu-model-artifacts-YOUR_PROJECT_ID/

STEP 11 — Create Cloud SQL PostgreSQL database:
  (Takes 5-7 minutes. Be patient.)

  COMMAND 1 — Create instance:
  gcloud sql instances create apu-db ^
    --database-version=POSTGRES_14 ^
    --tier=db-f1-micro ^
    --region=us-central1 ^
    --storage-size=10GB ^
    --no-backup

  COMMAND 2 — Create database:
  gcloud sql databases create apu_predictions --instance=apu-db

  COMMAND 3 — Create user (use a STRONG password, not this example):
  gcloud sql users create apu_user --instance=apu-db --password=CHOOSE_A_STRONG_PASSWORD

  COMMAND 4 — Get connection name (WRITE THIS DOWN):
  gcloud sql instances describe apu-db --format="value(connectionName)"
  Output example: apu-predictive-maintenance:us-central1:apu-db

  COMMAND 5 — Get public IP (WRITE THIS DOWN):
  gcloud sql instances describe apu-db --format="value(ipAddresses[0].ipAddress)"

STEP 12 — Run the database schema:
  Download Cloud SQL Proxy from:
  https://cloud.google.com/sql/docs/postgres/sql-proxy
  (Download cloud-sql-proxy.exe for Windows)

  PowerShell Terminal 1 — start proxy:
  .\cloud-sql-proxy.exe YOUR_CONNECTION_NAME
  (e.g. .\cloud-sql-proxy.exe apu-predictive-maintenance:us-central1:apu-db)
  Leave this running.

  PowerShell Terminal 2 — run schema:
  psql -h 127.0.0.1 -U apu_user -d apu_predictions -f infra/schema.sql

  You should see:
    CREATE TABLE
    CREATE TABLE
    CREATE TABLE
    CREATE INDEX x5

STEP 13 — Store secrets in Secret Manager:
  (In PowerShell, replace values with your actual ones)

  echo -n "YOUR_DB_PASSWORD" | gcloud secrets create db-password --data-file=-
  echo -n "YOUR_DB_HOST_IP"  | gcloud secrets create db-host --data-file=-
  echo -n "YOUR_CONNECTION_NAME" | gcloud secrets create db-connection-name --data-file=-

  Give Cloud Run access to each secret:
  gcloud secrets add-iam-policy-binding db-password ^
    --member="serviceAccount:apu-deploy-sa@YOUR_PROJECT_ID.iam.gserviceaccount.com" ^
    --role="roles/secretmanager.secretAccessor"

  (Repeat for db-host and db-connection-name)

STEP 14 — Update Cloud Run environment variables:
  gcloud run services update apu-app ^
    --region=us-central1 ^
    --set-env-vars ^
      GCS_MODEL_BUCKET=apu-model-artifacts-YOUR_PROJECT_ID,^
      GCS_DATA_BUCKET=apu-incoming-data-YOUR_PROJECT_ID,^
      GCP_PROJECT_ID=YOUR_PROJECT_ID,^
      DB_NAME=apu_predictions,^
      DB_USER=apu_user,^
      DB_HOST=YOUR_DB_HOST_IP
